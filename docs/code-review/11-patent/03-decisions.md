## 已知豁免（不是缺陷）

- **六种语言的 UI 字典**：`scripts/locale-dictionary-parity.spec.ts` 的 `PENDING_LOCALE_PACKAGES` 已书面豁免 `ui-patent-teams`（连同 ui-document-studio、ui-plugin-catalog、ui-todo-board），理由为「still being translated」。F-PAT-155 记录的是「README 未披露」，不是「豁免无效」。
- **`patentDeadline` 服务默认不发布、`patent-index-asset` 是纯库**：B1 已确认属有意设计，非断链。
- **团队标签页在每个会话视图都存在**（order 30）：README 与空态文案都按此设计，属产品选择。

## 建议的处置顺序

1. **F-PAT-130**（唯一 P1）：补 `paragraphs` 资产，或改共享判定层。这是专利域法律底座可信度的底线。
2. **F-PAT-157 / F-PAT-158**：一次 Web 端实测可同时解决两条（渲染幅度与回溯成本）。
3. **F-PAT-079 / F-PAT-122**：两处结构性依赖，各自独立可做。
4. 其余 P2/P3：按所在包的下一次维护窗口捎带。
