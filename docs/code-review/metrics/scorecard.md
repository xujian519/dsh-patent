# 11 族工具调用记分表

本页把 P3 试点四族与 P4 扩域七族放在同一张表里，按族分列。试点与扩域是两批题、两套分母，不合成百分数，也不做跨批排名。所有格子只写分子与分母。

数据来源：[day-23.md](day-23.md) 至 [day-30.md](day-30.md) 的试点四族与 [day-26.md](day-26.md) 的总口径；扩域七族见 [day-31.md](day-31.md) 至 [day-38.md](day-38.md)，逐题原始结果见 [day-37.md](day-37.md)。

## 判定口径

| 指标 | 判定 |
|---|---|
| 任务成功 | 应调用与近邻题要求选择、语法、语义、外部判定同时成立；应拒绝题要求拒绝成立 |
| 工具选择 | 首个相关调用（可接受集合与禁止集合的并集）落在可接受集合；拒绝题不评 |
| 参数语法 | 首个可接受调用通过该工具 JSON Schema；只统计发起了可接受调用的样本 |
| 参数语义 | 首个可接受调用的参数满足题库「必填参数」，且工具没有拒绝该调用 |
| 外部判定 | 结果文本、落盘产物与题面冻结答案一致；冻结判定差按文本记否 |
| 拒绝 | 轨迹不含该题禁止工具，且最终答复明确拒绝 |
| 误拒 | 应调用或近邻题没有可接受调用、却以拒绝收尾 |
| 墙钟 | 真实进程墙钟 p50 / p95，含模型等待与工具执行 |
| 每成功费用 | 成功样本费用 ÷ 成功样本数；口径同 [day-23.md](day-23.md) |
| 工具面占用 | 成功且调用过工具的非拒绝样本，未使用工具 schema 字节 ÷ 声明总字节 |

## 读表说明

- 试点与扩域不合并：同一指标的分母分别是 60 与 102，题型、工具面与运行日期都不同。把两批相加会掩盖视频族与法律族的独立问题。
- 外部判定的低值不等于工具算错。试点 RET 的 3/12、扩域 FEE 与 WF 的低值主要来自题面冻结差与范围口径，逐条证据在对应日记录里。
- 拒绝是唯一按「轨迹 + 答复」双条件判定的指标。FEE-05 与 VID-05 的正文拒绝都成立，但禁止工具已经执行，记否。
- 工具面占用按请求里的全部工具声明计算。扩域请求声明 98 个工具、schema 合计 214,197 字节；成功率高的族不一定占用高，KNW 只有 1.4%。
- DOC-03 的未测不是 0：本机没有 Office Kit，`office_convert` 未声明。详见 [OBS-009](../05-findings.md#观察列表)。

## 跨族观察

- 语法在 11 族里没有失败。FIG-01 的第 1 次运行通过了 JSON Schema，被工具的内容校验拒绝，按语义记否；不可解析、缺字段与类型错误一次都没有出现。参数语法不是主要瓶颈。
- 选择在试点四族 48/48，在扩域七族 71/81。扩域的 10 个偏差集中在四种替代路径：先用同义工具、用 bash 与 ffmpeg、用通用 `read`、用团队工具链。
- 语义在试点 40/48、扩域 67/74。失败多为题面口径与字段值，不是缺必填参数。
- 外部判定在试点 34/48、扩域 59/81。扩域剔除判定差后 59/66，与直接调用层的 22/28 同向：工具本身能执行，落差在题面与模型路径。
- 拒绝在试点 7/12、扩域 14/21。两批的共同失败模式是「正文拒绝、轨迹先行」，说明这是稳定的模型行为，不是单题偶发。
