## 实施的发现

### F-PAT-088：中文单位范围恢复为单一数值区间

`novelty/numeric-range.ts` 的 `RANGE_PATTERN` 与 `SUFFIX_BOUND_PATTERN` 原先只使用拉丁单位的 `NUMERIC_UNIT_ALTERNATION`，导致「20毫米至90毫米」拆成两个数值点。现复用既有 `NUMERIC_ANY_UNIT_ALTERNATION`，统一中文、拉丁与符号单位；没有新增第二份单位表。新增区间提取与重叠判定回归，`patent-tools` 的共享词汇用例同步加入该中文单位区间，现有 12 个共享用例继续约束新颖性分析与说明书校核的一致解释。既有双语 Agent Note 已更新为当前词汇与用例数。

### F-PAT-072：模糊词扣分排除非数值语境

`analysis-report/build.ts` 只对邻近数值的「约」（含「约为」「约是」）和跟在数值及可选已知单位后的「左右」扣分。「约束」「节约」「左右两侧」不再触发清晰度惩罚；「大约」「大概」「若干」「优选地」与每项扣五分的既有规则不变。回归同时覆盖误报消失与数值语境仍扣分。
