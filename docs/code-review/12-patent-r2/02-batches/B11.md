执行日期：2026-11-29。主维度：质量与精简。

## 范围与口径

- 60 个 `src` 文件、18,626 行：`atoms/` 11 个分析原子，`figure/` 49 个附图、几何、渲染与交付模块。与计划记 60 一致。
- 台账 `batch` 列把这批文件标为第一轮 B6「分析与附图」，与本轮批次表不是同一编号体系；沿用 B4/B7/B8/B9/B10 做法，未改台账。
- `figure/claim-figure-coverage.ts` 与 `figure/numeral-store.ts` 是台账未登记的新文件，随本批一并审阅；两者都已被工具入口消费。
- 漂移文件 4 个：`figure/compliance.ts`、`figure/geometry.ts`、`figure/leader-line.ts`、`figure/svg-annotate.ts`。其余 56 个在第一轮签字后内容未变。
- 60 个文件全部至少通读一次；4 个漂移文件按当前内容复核，未委派子代理。

## 审阅方法

- 行为探针（`tsx` 直接调用源码）覆盖：FreeCAD 脚本路径含 `$&`/`$'`/`` $` ``、DOT 规范化 id 相撞、结构渲染残留、实施例块超预算、页面边距 NaN/越界、SVG marker 未量测、曲线图最小画布。
- 真实 FreeCAD smoke：`figure-freecad-real-render.spec.ts` 的 31 个用例在本机 FreeCAD 上执行，覆盖结构投影、装配体、局部放大、剖切几何与剖面线；结构投影后模板 SVG 残留由此确认。
- 静态清单：`new Error(`、`catch`、`as unknown`/`as never`、`v8 ignore`、`skip`、`TODO`、相邻 JSDoc、`recordNumberOr` 使用面逐条回源；本批没有新增项。
- 出口可达性：核对 `analyze_patent_figure`、`compare_figure_analysis`、`generate_patent_figure`、`check_figure_consistency`、`check_claim_figure_coverage` 的工具注册与 `figure/*` 内部调用面；`svg-to-dxf`、`index-store` 分别由附图工具与检索工具消费。
- 基线测试：本批 133 个测试文件、2,542 个用例通过，4 个按外部二进制能力跳过。

## 缺陷（用户确认后已全部修复）

| ID | 级别 | 位置 | 证据与影响 | 最小修复 | 状态 |
|---|---|---|---|---|---|
| S-PAT-048 | P3 | `figure/freecad-section-script.ts:94`、`freecad-hatch-script.ts:82`、`freecad-structure-script.ts:316` | 三处脚本构建器用字符串参数调用 `String.replace('__PAYLOAD_LITERAL__', payload)`，替换值里的 `$&`、`$'`、`` $` `` 被当作替换模式展开。探针：`modelPath: "/tmp/a$'b.step"` 时内嵌 JSON 被截断，`$&` 时路径变成 `__PAYLOAD_LITERAL__`，Python 侧 `json.loads` 失败。 | 替换值改用函数返回（`() => payloadLiteral`），三处同改。 | 已修复 |
| S-PAT-049 | P3 | `figure/dot-builder.ts:515`、`:625` | 流程图与框图只按原始 id 建索引，`a b` 与 `a_b` 经 `sanitizeId` 都变成 `a_b` 后输出两条同 id 节点声明，后者覆盖前者且后继/连接指向合并后的节点。层级图与状态图已在遍历时拒绝重复 id。 | 新增 `assertUniqueIds`，在两个 builder 分配标号前按规范化 id 去重并抛 `DotBuildError('unknown_id')`。 | 已修复 |
| S-PAT-050 | P3 | `figure/freecad-renderer.ts:304`、`:354` | 结构投影脚本在交付目录写 `.freecad-structure-template.svg` 与 `.freecad-transient`，渲染结束只清 `.freecad-home` 与 `.py`。真实 FreeCAD 渲染后模板 SVG 留在输出目录。 | `FreeCadScriptRequest` 增加 `cleanupPaths`，结构链路传入模板与 transient 目录，`finally` 内递归清理。 | 已修复 |
| S-PAT-051 | P3 | `atoms/slop-gate.ts:156` | 实施例块超预算但总分过线时 `passed` 为 false，报告写「需修订」，提示却只在 `!score.passed` 时生成。探针：总分 35、实施例 200/50 时无 `slop_revision_hint`，回退重写没有篇幅方向。 | 只要 `!passed` 就组装提示；总分提示与逐块超预算明细（序号、字数、上限）合并。 | 已修复 |
| S-PAT-052 | P3 | `figure/dot-builder.ts:320` | `resolvePageBundle` 只检查 `marginCm <= 0`，`NaN` 比较为 false 直接放行；A4 + 100cm 边距也放行并输出 `size="-70.47,-67.05"` 与 `margin="NaN,NaN"`。 | 边距改查 `Number.isFinite` 与正数；同时给 `pageSize` 时要求两倍边距小于页面短边，否则 `invalid_page`。 | 已修复 |
| S-PAT-053 | P3 | `figure/svg-to-dxf.ts:72` | `scanSvg.unmeasured` 记录 marker 端头、CSS 样式、未展开引用等未量测原因，`svgToDxf` 只转述填充与曲线降级。探针：带 `marker-end` 的箭头 SVG 转换成功但 `warnings` 为空。 | 把剩余 `unmeasured` 原因并入 `warnings`；已导致拒绝的 viewBox/变换原因在此之前已抛出。 | 已修复 |
| S-PAT-054 | P3 | `figure/plot-diagram.ts:327` | 画布只校验正有限数，不校验扣除左右边距、下轴带与图例后是否仍有绘图区。探针：20×20mm 得到 `plotWidth=-10`，横轴落在 x=22 的画布外；多序列图例还会继续吃掉高度。 | 计算后要求 `plotWidth > 0` 且 `plotHeight > 0`，否则 `invalid_input` 并说明是宽度还是高度不足。 | 已修复 |
