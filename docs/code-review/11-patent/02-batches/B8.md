## 采纳并修复（7 条）

- **F-PAT-124**（P1）rule-lock 把已转录的关键条文报成「未判定」：随包 lineage 把专利法第 62/67/71/77 条标为 `unverified`（因 1984/1992 版本未转录），判定直接采用该状态覆盖 baseline，第 71 条损害赔偿被判「未判定」而同一次 `law_verify` 判 `valid`。改为：`unverified` 只表示沿革不可考，不覆盖现行条文的转录判定。
- **F-PAT-123**（P2）类型不适用的费用阶段被渲染成「未核对」：查询外观设计的实审费时唯一条目被类型过滤，合计 `0.00` 与「这不等于本案没有费用」并列。改为：全部被类型排除时说「对该专利类型不适用，无需缴纳」。
- **F-PAT-125**（P2）PCT 效力终止时点写成 30 个月：在「30 个月已过、32 个月未满」这一缴宽限费的窗口里报「效力终止」，可能致案件被放弃。改为按 30/32 两个条目分别措辞。
- **F-PAT-126**（P2）TRIZ 空格被说成「经典矩阵无解」：234 个非对角空格是转写缺口，文案却写成 `The classical matrix lists no recommendation`。改为明示 matrix gap。
- **F-PAT-127**（P2）旧 PDF 被当作本次渲染产物：Chrome 退出 0 后只判文件存在，同名旧 PDF 会被当本次结果交付。改为 spawn 前删除同名旧文件。
- **F-PAT-128**（P2）arXiv 的 200+Error 响应被缓存：`looksValid` 只判根元素，错误条目进缓存 5 分钟，模型按「稍等重试」永远读到同一错误。改为同时排除 `/api/errors` 与 `Error` 标题。
- **F-PAT-129**（P2）`paper_download` 直接写最终文件：改用 `@deepseek-ai/dsh-atomic-write`（新增 workspace 依赖，模块图重生成无变化）。
