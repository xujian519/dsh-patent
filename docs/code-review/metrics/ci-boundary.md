# CI 与周期评测分界清单

本文件是工具调用指标 P6（D43–D45，[#938](https://github.com/xujian519/dsh-patent/issues/938)）的分界产物。它只记录裁定：哪些检查可以进 CI，哪些维持周期评测，以及每条 CI 检查拒绝的一个反例。本阶段不改 CI 配置、业务代码、依赖或 `daily/`。

## 判定规则

一条检查同时满足四条才可进 CI：

1. 不依赖真实模型采样，也不依赖模型名、提示词或 token 计费。
2. 反例能机械判定：退出码、JSON 字段、文件内容、进程或目录状态之一可读。
3. 运行环境缺少外部依赖时显式跳过并打印原因，不把跳过记成通过。
4. 先用一个真实反例证明检查会红，再设为阻塞。

只满足前三条但当前会红的检查记为「条件采纳」：先修对应发现，再开门禁。真实模型的选择、拒绝、墙钟、费用与上下文占用不进 CI。

## CI 检查

| 编号 | 层 | 检查 | 拒绝的反例 | 依赖与跳过 | 裁定 |
|---|---|---|---|---|---|
| CI-01 | 直接调用 | 参数 JSON 可解析，且通过该工具的 JSON Schema | `{` 不可解析，或 `limit` 写成字符串仍被执行 | 15 个试点工具与 28 道扩域直接调用；无网络 | 采纳 |
| CI-02 | 直接调用 | 缺必填与空输入在参数层 fail-closed | `law_verify {}` 返回成功或只有文案；`validate_specification {}` 返回 `passed=false` 的成功结果 | F-LEG-015、F-PAT-057 修复后 | 条件采纳 |
| CI-03 | 直接调用 | 路径穿越不越界写入 | `build_patent_filing` 用 `../p1-outside-probe` 创建目录或写文件 | 工作目录探针；无网络 | 采纳；错误码归 CI-07 |
| CI-04 | 直接调用 | 注入字符按字面量处理 | `$(printf p1canary)` 被执行、写出文件或启动进程 | 无外部依赖 | 采纳 |
| CI-05 | 直接调用 | 超长正文按 contained 记通过 | 8 万字正文导致崩溃、半成品或残留 | 按 P5 的口径建议，contained 记通过 | 采纳，口径随本清单更新 |
| CI-06 | 直接调用与脚本 | 调用结束后无进程、临时目录或越界产物 | 任务结束后子进程仍在，或工具临时目录未删除 | `ps` 探针；无网络 | 采纳 |
| CI-07 | 直接调用与脚本 | 预期失败带 `error.code` | 失败结果只有「草案校验失败」文案，`tool/result.error` 为空 | F-CROSS-005、F-CROSS-006 修复后 | 条件采纳 |
| CI-08 | 脚本场景 | 外部判定闭环 | `isError=false`，但产物缺失、内容不符或条数超过题面上限 | 只收离线题；知识库与网络题显式跳过 | 采纳 |
| CI-09 | 脚本场景 | 注入失败后恢复 | 同名同参数原样重试、重试超过 2 次，或宣称成功而外部判定不成立 | 超时、空结果、取消三种注入；无网络 | 采纳 |
| CI-10 | 脚本场景 | 首调失败不留半成品 | 失败前写出半份 JSON、空目录或部分 DOCX | 与 CI-08 共用 fixture | 采纳 |
| CI-11 | 脚本场景 | provider 次数与账本一致 | 账本总额超过预算，或 provider 次数与成功次数不一致 | mock provider；F-VID-011 修复后 | 条件采纳 |
| CI-13 | 直接调用 | 已声明参数被执行或被拒绝 | `transition` 带 `planSteps` 返回 `ok: true`，但任务同步没有发生 | F-PAT-058 修复后 | 条件采纳 |

CI-01、CI-03、CI-04、CI-05、CI-06、CI-08、CI-09、CI-10 在现有记录里已经通过，可以先抽 fixture。CI-02、CI-07、CI-11、CI-13 在修复对应发现之前会红，不设阻塞。

## 不进阻塞 CI 的检查

| 项 | 原因 | 处置 |
|---|---|---|
| P-RET-02、P-RET-03 的外部判定 | 依赖 nuo 网络与远端返回 | 周期评测或人工复核；CI 跳过时打印原因 |
| P-RET-01、P-RET-04 | 依赖本机知识库或 wiki | 有库时跑，无库时跳过，不记通过 |
| P-LGL-04 的空库场景 | 依赖本机法律库；空库是有效状态 | 有库时跑；空结果不记失败 |
| DOC-03 | 本机没有 Office Kit，`office_convert` 未声明 | 维持未测，不记 0 |
| 真实视频 provider 的真实账单 | 需要外部 provider 与预算 | 由 CI-11 的 mock 覆盖不变量；真实账单留在周期评测 |
| 真实模型五项 | 读数随模型、提示词与采样次数变化 | 维持周期评测，见 [day-44.md](day-44.md) |
| 响应时间与 token 费用 | 依赖真实进程、模型等待与计费单价 | 只作周期评测，不设阻塞阈值 |
| 峰值内存 | 两批都没有采样 | 下一周期补采样，不作为当前门禁 |

## 十项指标的分界

| 指标 | 可测层 | 裁定 | 依据 |
|---|---|---|---|
| 工具选择 | 真实模型 | 周期评测 | CI 的脚本按题面填参，没有模型选择过程 |
| 参数填充 | 语法进直接调用；语义进真实模型 | CI-01；语义不进 CI | 脚本按题面填参，不能替代模型生成的参数语义 |
| 调用闭环 | 脚本 | CI-08 | 外部判定成立且有配对结果 |
| 拒绝与鲁棒 | 鲁棒进 CI；拒绝进周期评测 | CI-01、CI-03、CI-04、CI-05；拒绝率不进 CI | 拒绝依赖模型轨迹与最终答复 |
| 响应时间 | 真实模型 | 周期评测 | 墙钟含模型等待与进程启动，波动大 |
| 成本效率 | 真实模型 | 周期评测 | 依赖 token 单价与真实 API 费用 |
| 可解释性 | 直接调用、脚本 | CI-07 | `error.code` 与配对结果可机械检查 |
| 上下文利用率 | 真实模型 | 周期评测 | schema 体积代理依赖该次请求的工具声明 |
| 错误恢复 | 脚本 | CI-09 | 注入后二调的外部判定可机械检查 |
| 资源利用率 | 直接调用、脚本、周期评测 | 进程与残留进 CI-06；provider 次数与峰值内存不进阻塞 CI | provider 账单与内存采样依赖外部环境 |

## 维护规则

- 题库或工具行为变化时，直接调用基线作废并重跑；CI fixture 跟随题库版本更新，不保留旧断言。
- 工具目录增删工具时，CI fixture 与 [10-tool-metrics-plan.md](../10-tool-metrics-plan.md) 的工具族表在同一改动里核对。
- 跳过必须有可见原因；把跳过记成通过会让门禁失去意义。
- 条件采纳的检查在对应发现修复后单独开门禁，不与业务修复混在同一个 PR。

## 验收

本清单没有把响应时间、token 费用或工具选择准确率写成阻塞 CI。三项都只出现在周期评测；CI 只覆盖参数、闭环、可解释性、恢复、半成品与残留这些与模型采样无关的检查。
