## 5. 升级指南

本结项不新建升级指南。

审查窗口里、由本轮审查引入、并且外部可感知的变更，是无法读取的款/项数字。指南已经在 `docs/upgrade-guide/v0.2.2-rc.1/malformed-citation-numerals/`。当前版本是 `0.2.2-rc.2`，那份指南留在原来的版本目录里，本结项不搬移。

D26 改变的是取消之后的任务状态：迟到的成功轮询不再覆盖 `cancelled`。这把运行时收回到已经写明的取消语义，不改 `dsh` 命令、配置键、Session 格式或已发布包入口。

同一时期仓库里还有 CUA、forge 等升级指南。它们不属于这四领域的审查，本报告不重写。

未合入的 #803 与 #806 若带上外部可感知的破坏性变更，由那些 PR 自己补指南。
