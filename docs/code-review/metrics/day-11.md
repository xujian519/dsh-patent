## 怎么扫

每次调用返回后，用进程表查看新出现的进程，并比较工作目录里的新文件。进程表里唯一新增的命令是这次查看自己启动的 `ps -ax -o pid=,ppid=,command=`。把它排除以后，没有留下工具启动的子进程。工作目录里唯一的新文件是上述 docx。`outsideCreated` 在题面调用和路径探针里都是 false。

驱动器记下的耗时含会话结算等待，不填墙钟列。进程内存读数同样不填利用率。
