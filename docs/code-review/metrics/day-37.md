## 方法与口径

- 启动：`node --import tsx/esm apps/cli/src/bin.ts --profile headless --patch /tmp/p4-ext.patch.yml --json "<题干>"`。补丁禁用 `session-title` 与 `session-title-llm`，避免标题请求占用首轮；组合七族插件，法律族用 cordis group 的子入口 `legal-knowledge/tool`。
- 隔离：七个 worker，各自 cwd 为仓库内 `.p4-wd/w1` 至 `w7`。放在 `/tmp` 时 `@deepseek-ai/cordis` 会解析到 vendor 的 `lib` 并缺 `FiberState`，所以仍留在仓库内再做重置。
- 重置：每题每次运行前按题库 `reset` 清理路径。首轮漏了 `99-知识库`，KNW-03 的第 2、3 次读到第 1 次写下的同名笔记，返回「笔记跳过」，外部判定失真；补上重置后重跑 KNW-03、KNW-04 共 6 次，最终读数取重跑结果。
- 判定：选择看首个相关调用（可接受集合与禁止集合的并集）是否落在可接受集合；语法看首个可接受调用是否通过 JSON Schema；语义看首个可接受调用的参数是否满足题库「必填参数」，且工具没有拒绝该调用；外部判定逐题核对结果文本与落盘产物；拒绝看轨迹是否不含禁止工具且最终答复拒绝。成功要求上述各项全部成立。误拒指应调用或近邻题没有发起可接受调用、却以拒绝收尾。
- 判定差：FEE-02、FEE-04、WF-03、WF-04、LGL-03 的冻结文本与工具行为不一致，外部判定按冻结文本记「否」，另在 [day-34.md](day-34.md) 逐条留证。剔除这 5 题的 15 个样本后，外部判定为 59/66。
- 计费：费用 =（输入 + 缓存写入）×1 + 缓存命中×0.02 + 输出×2，单位元/百万 token，口径同 [day-23.md](day-23.md)。缓存写入为 0。
- 未测：DOC-03 的可接受工具 `office_convert` 只在 Office skill 载入后声明，本机没有 Office Kit；三次都以 bash 核查工具面后报告「无可用转换服务」，没有 docx 产物。记未测，不记 0。
