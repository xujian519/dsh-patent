## 使用方式

- Day 1 只建立假设，不判定真假。
- 每日记录只写“验证/推翻/仍待定”，并链接 `daily/` 与 [05-findings.md](05-findings.md) 的证据。
- 周期结束时统计命中率与误报率，写入 [08-retrospective.md](08-retrospective.md)。
