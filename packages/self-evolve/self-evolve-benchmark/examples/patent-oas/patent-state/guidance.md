# 专利作业规范(agent state 种子)

本文件是执行专利撰写/分析任务时的作业规范与检查清单。执行者(executor)在开始任务前先通读本文件,按其 checklist 完成交付物;优化者(optimizer)以改进本文件为编辑对象;实现者(applier)负责把候选改动写入本文件。本文件是通用作业规范,不含任何具体案例的答案。

## 通用工作原则

1. 检索先于结论:任何结论(新颖性/创造性/侵权)都必须先有检索或现有技术依据,不得凭空断言。
2. 法条核验:引用法条(专利法及其实施细则、《专利审查指南》)时核对条文序号与表述。
3. 单独对比原则:新颖性评价坚持逐篇单独对比;创造性评价才允许结合,且需论证结合启示。
4. 区别特征认定准确:以最接近的现有技术为基准,认定区别技术特征时不遗漏、不扩大。
5. 实际解决的技术问题:基于区别技术特征确定,避免过于上位或偏离区别特征。
6. 结论明确:给出确定结论,结论与论证一致,不自相矛盾。
7. 免责声明:涉及法律意见/诉讼风险的交付物,文末附"以上为初步分析意见,不构成正式法律意见;如需正式意见,请结合完整案卷咨询执业律师"类声明。

## 交付物格式

- 答复意见书:意见陈述 + 结论 + 法条引用,结构完整。
- 权利要求书:标注权利要求序号,前序 + 特征 + 其特征在于,从权引用正确。
- 申请文件(交底书撰写):权利要求书 + 说明书五部分(技术领域、背景技术、发明内容、附图说明、具体实施方式)+ 不超过 300 字的摘要。
- 侵权比对报告:逐特征比对表 + 等同分析 + 明确结论 + 风险定级。
- 新颖性/创造性分析意见:分条论述 + 法条依据。

## 检查清单(完成前逐项核对)

- [ ] 是否先执行检索/引用现有技术,再下结论?
- [ ] 区别特征是否准确、完整?
- [ ] 实际解决的技术问题是否与区别特征对应?
- [ ] 结论是否明确,且与论证一致?
- [ ] 法条引用是否核对正确?
- [ ] 输出是否符合对应交付物格式?
- [ ] 独立权利要求是否只写必要技术特征,实施例参数与优选方案是否落到从属权利要求?
- [ ] 说明书是否对独立权利要求的每个必要技术特征给出可实施的实施例(A26.3)?
- [ ] 权利要求的概括是否有说明书实施方式支撑,并列下位方案是否都有记载(A26.4)?
- [ ] 是否已附免责声明(如适用)?
