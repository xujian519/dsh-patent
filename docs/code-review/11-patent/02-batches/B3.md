## 采纳并修复（4 条 + 1 条待决策）

- **F-PAT-068** 证据权重只校验 `typeof`：YAML 的 `.nan` / 负数会进入加权平均，综合分变 NaN 或负数。
- **F-PAT-069** 文本日期提取的 8 位分支无边界：12 位中国申请号会被截出前 8 位当成公开日。
- **F-PAT-070** 调用方取消后内部计时器未清除：子进程收尾慢于剩余超时时，主动取消被报成内部超时。
- **F-PAT-071** 事实黑板 `fromJSON` 不校验：损坏记录抛原始 TypeError，恢复方拿不到「记录损坏」的信号。
- **F-PAT-072** 清晰度评分的模糊词表按子串匹配，「约束」「左右两侧」被误判 —— **待决策**，改判定即改领域口径，留给代理师定。

## 复核后否决（3 条）

- **模型补分未截断**：不成立。边界处的 `asScoreEntry` 已校验 `0..100` 并取整，且 JSON 无法携带 NaN/Infinity。
- **`mapChunks` 把 `aborted` 折叠成 `error`**：不成立。`failure.code` 已保留；provider 侧中止按可重试降级处理是合理的，改成抛取消错误会把整图打断，比现状更糟。
- **月级日期口径不对称**（公开侧推月末、截止侧取月初）：方向是「宁漏判不误伤」，且公开侧已有注释说明，记为观察而非缺陷。
