# B10 patent-tools 撰写与校核

执行日期：2026-11-29。主维度：质量。

## 范围与口径

- 21 个 `src` 文件、5,190 行（台账行数），与计划一致：`tool/` 下 19 个撰写与校核模块，加 `spec-types.ts` 与 `validate-specification.ts`。
- 台账 `batch` 列把这 21 个文件标为第一轮 B5「撰写与校验」，与本轮批次表不是同一编号体系；沿用 B4/B7/B8/B9 做法，未改台账。
- 漂移文件 3 个：`spec-figure-marks.ts`、`spec-types.ts`、`validate-specification.ts`。其余 18 个在第一轮签字后内容未变。
- 21 个文件全部至少通读一次；3 个漂移文件按当前内容复核，未委派子代理。

## 审阅方法

- 行为探针（`tsx` 直接调用源码或经 `executeToolFixture` 走工具边界）覆盖：空白名称、重复实施例标题、重复章节标题、标准引证、摘要方案编号、空交底原文、风险比例越界、实用新型措辞。
- 静态清单：`new Error(`、`catch`、`as unknown`/`as never`、`v8 ignore`、`skip`、`TODO`、相邻 JSDoc、`requireNonBlankText` 使用面逐条回源；本批没有新增项。
- 出口可达性：核对 `draft_claims`、`draft_specification`、`claim_lint`、`claim_chart_build`、`validate_specification` 的公开导出与 preset 工具注册；`validate_specification` 由 `spec-check` 原子、成文预检与 `review_patent_application` 消费。
- 基线测试：本批 14 个测试文件、369 个用例通过。
