## 已排除候选

| 候选 | 排除理由 |
|---|---|
| `verify` 与 `citator` 对「声明了 `supersededBy` 但 `versions` 为空」的处理不同 | `verify` 按 `staleSections` 放行未受影响节，`citator` 整体 fail-closed；两边都有针对性用例钉住。`staleSections` 完整时前者更精确，改成一致会推翻一条有意固化的语义，收益不足。 |
| 删除 `DEFAULT_RULE_LOCK_AS_OF_KEY` 与 `lockProvisions` 的 `asOf` 参数 | 两者都在 `scripts/plugin-entry-existing-exports.ts` 的公开面基线里，删除属已发布 API 的破坏性变更，需要同步基线并写升级指南；本批只纠正原子的输入契约，保留库层保留面并写明未用。 |
| `support.ts` 与 `reference.ts` 的再导出层 | 两个模块是 `patent-law` 文档化的公开入口（shared scoring 与引用解析），不是无消费者的间接层；保留。 |
