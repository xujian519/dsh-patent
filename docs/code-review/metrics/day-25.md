## 本轮异常

P-SPC-03 的 HTML 落在「委托方：甲」，题面锁定的是「委托方甲」；文件存在、发明名称与结论正确，语义与外部判定仍按冻结口径记否。这是三轮里唯一一次把字段拆成标签与值。
