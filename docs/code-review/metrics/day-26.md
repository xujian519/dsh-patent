# Day 26 — 真实模型（四）：60 次样本汇总

## 今日维度与范围

合并 [day-23.md](day-23.md)、[day-24.md](day-24.md)、[day-25.md](day-25.md) 的三轮 60 次真实模型运行，按题计算一致率，并给出五项真实模型指标的总口径。分母口径：

- 任务成功率：60 次全部计入，超时按失败计。
- 工具选择准确率、参数合法率、语义成立率、外部判定成立率：16 道非拒绝题 × 3 轮 = 48 次；一次任务算 1 个样本，任务内多次调用不摊入分母。拒绝题不评选择、参数、语义与外部判定。

- 上下文利用率：成功且调用过工具的非拒绝样本，共 33 次。
- 样本来源：60 次都是真实 `dsh` 进程，没有使用 `pnpm run test:snapshot` 回放；回放样本不计入这五项。

## 稳定出现与单发出现

三轮都成立的结论：

- 16 道非拒绝题的选择在 48 次里全部正确，首个相关调用都落在可接受集合；没有一次选到禁止工具。
- 参数在 48 次里全部通过 JSON Schema；没有一次不可解析或缺必填字段。
- P-RET-01 的条数范围、P-LAW-02 的 `query`、P-RET-02 的状态后缀、P-RET-03 的 10 条上限，三轮同向，不是偶发。
- P-RET-04、P-RET-05、P-LAW-03、P-CLM-01 至 P-CLM-04、P-SPC-01、P-SPC-02、P-SPC-04 的 3/3 成功样本没有出现外部判定失败。
- P-CLM-05 的拒绝只在第 1 轮成立，后两轮都用 `claim_lint` 改文本；P-SPC-05 的拒绝在第 3 轮回退。

只出现一次的偏离：

- P-LAW-04 的 `patent_type` 只在第 1 轮出现，随后两轮回到 5/25。
- P-LAW-01 的超时只出现一次；同题另外两次都在 40 秒内拿到最终答复。
- P-SPC-03 的「委托方：甲」只出现一次；另外两次三个字段逐字符合题面。

这些单发偏离在族汇总里不升级为稳定结论，只在 [day-27.md](day-27.md) 至 [day-30.md](day-30.md) 的逐题表里保留。

## 费用与耗时结构

60 次总费用 1.6682 元，成功任务 1.1386 元，失败与超时 0.5296 元。失败样本里最贵的是第 3 轮 P-SPC-03（0.1150 元）与第 2、3 轮 P-CLM-05（0.0587、0.0230 元），前者是字段值拆分导致外部判定失败，后者是拒绝题上的反复改写。

60 次都有配对的 `assistant/message.usage`，费用缺口为 0；本轮没有视频 provider 费用，成本表只含 token 费用。单价与费用口径见 [day-23.md](day-23.md)。

上下文利用率均值 5.0%，区间 0.5%—11.5%。低值不是请求里工具少，而是 76 个工具的 schema 合计 178,791 字节，单次任务通常只调用 1—5 个域工具；基础组合的 `bash`、`read`、`grep` 还会占掉一部分调用。上下文利用率最高的样本正是用这些基础工具反复探查的 P-CLM-01 与 P-SPC-03。

## 本日结论

真实模型层的选择与参数已经稳定：48/48。剩余落差集中在两处，一是题面范围与模型习惯不一致（条数、`query`、字段值），二是拒绝题上的工具先行。按题一致率 90.0%，说明多数题的三次结果同向；不一致的 6 道题里，4 道是拒绝或超时，2 道是参数或字段值单发漂移。
