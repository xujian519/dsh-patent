## 采纳并修复（12 条）

- **F-PAT-090**（P2，本批唯一）跨图一致性把后图名称记到首图号下：首图该标号没有名称时，后图名称回填后又被当作「首图的原值」写进冲突报告，模型会去改错那张图。改为按「首个非空名称 + 所在图号」归属。
- **F-PAT-095 / 094** 两处模型可见契约：生成附图的 `filename` 静默把中文与空格替换为 `_` 却未披露；`analyze_patent_figure` 的 `figure_number` 输入是 `number`、无正整数校验（输出却是 `integer`）。前者补披露，后者改 `integer` 并在 execute 校验。
- **F-PAT-098 / 097 / 096** 三处「缺失读成通过」：分析报告在 LLM 补分失败时静默少两维；`patent_eval` 未提供要求清单时仍打印「覆盖度 100%」；受理条件「未执行」时待核项为空、只靠下游字符串匹配兜住。分别补「未评分」行、改抽查口径、补 `ADM-UNASSESSED` 待核项。
- **F-PAT-092 / 093** 附图检查与文案：交付检查未展平曲线，压弧的图号可被错误豁免用词检查；两处模型可见警告暴露引擎实现词汇（「两步分析第一步」「parts/anchor」）。
- **F-PAT-091 / 100** 子进程资源与边界：FreeCAD 的隔离目录与脚本写在交付目录且从不清理；剖切几何的三个叶子字段（`path`/`solids`/`distance`）未校验。
- **F-PAT-099** `provider` 与 `model` 只配置一半会被静默丢弃并回落宿主默认模型；改为加载期 `setup_required`。
- **F-PAT-089** 模块 JSDoc 的工具数 38 与实际 39 不一致（TRIZ 工具加入后未同步）；新增用例钉住 39 个注册工具名。
