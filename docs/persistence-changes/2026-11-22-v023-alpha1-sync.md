<a id="compatibility"></a>
## Compatibility

Same-version. `patent-teams-report` is one object variant carrying the relay form and its sender identity, `self-evolve` is attribution-only, and `patent-rule-gate` carries the `ContextFormed` union so the variant set it contributes grows with that public form vocabulary. No existing upstream variant changed, no property became required, and `SessionHeader.version` is unchanged, so readers that accept the fork history still read sessions written before the merge.
