## 观察（不构成发现）

- **颜色纪律是这个包的强项**：5 个样式文件零字面颜色值，全部走 `--dsw-alias-*`；暗色配对完整；`prefers-reduced-motion` 覆盖 pulse/sweep/transition，全仓很多组件没写。
- **折叠与投影同源**：卡片与 Teams tab 跑同一个 reducer，测试有专门的「live append 与完整重放收敛」用例，两者不可能互相矛盾。`teams-view.ts` 是唯一读 `node.data` 的 view builder（其余从 timeline 派生），契约里 `data: unknown` 使两处 `as` 成为必需而非疏漏。
- **`loadOlder` 引用稳定**：slot 的 inject 结果按 (entry, session binding) 缓存（`scoped-slots.tsx` 的 `cachedSessionInject`），不会因重渲染反复触发 drain effect；`useSessions(..., shallowEqual)` 对 `ReadonlySet` 有效（zustand 的 `shallow` 按 size + 成员比较）。
- **`inject` 抛错会让 Teams 标签退役**：与 `ui-trajectory` 同构，`abdicate` 后该 entry 被永久排除出 slot 投影。这是仓库既定模式（测试明确断言 fails loud），不记为本批缺陷。
- **`★`/`⊘` 等符号**：`⛨`（U+26E8）在常见系统字体中覆盖概率低，有渲染成 tofu 的风险；其余四个（＋ ◔ ⊘ ✉）风险较低。

`card.expected.md` **未改动**：web fixture 中的成员都是 Idle，没有运行中成员，因此本批新增的 sr-only「打开」文本不出现；jsdom 侧卡片断言（成员、任务、状态、依赖、消息计数）全部通过，证明卡片输出未变。
