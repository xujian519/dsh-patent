<a id="compatibility"></a>
## 兼容性

同一版本。`patent-teams-report` 是携带 relay 形式与发送方身份的单个对象变体，`self-evolve` 仅作归属标记，`patent-rule-gate` 携带 `ContextFormed` 联合，因此它贡献的变体集合随该公开形式词汇增长。既有上游变体未改变，没有属性变为必填，`SessionHeader.version` 保持不变，所以接受 fork 历史的读取方仍能读取合并前写入的会话。

<a id="verification"></a>
## 验证

`pnpm run verify-persistence-changes` 用全部历史记录校验这四个根，`pnpm run gen-persistence-catalog` 已从合并树重新生成 `docs/persistence-schema.json`。
